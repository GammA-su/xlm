## 2. Implemented Architecture & Components

### 2.1 Candidate Catalog Draft & Validation (`src/xlm/data/sources/catalog.py`)
- **`CandidateSourceEntry`**: Pydantic schema encapsulating source metadata, provider designation, repository URI, immutable snapshot revision, view specifications, split definitions, schema mappings, licensing review, usage policies, and explicit operator approval flags.
- **`DatasetCatalogDraft`**: Container validating candidate numbering (1..N), uniqueness of source IDs, repository names, and catalog-level policies (`deny_direct_sources`, `allow_silent_fallback`).
- **Flexible Catalog Count**: Architecture supports generic catalogs of any size without hard-coding 20 into the prober or gate algorithms, while authoritatively verifying the required 20-candidate catalog in `manifests/datasets.catalog.yaml`.

### 2.2 Denial & Policy Safeguards (`src/xlm/data/sources/policy.py`)
- **Strict FineWeb Banning**:
  - Direct check `check_direct_source_denial()` raises `DirectSourceDeniedError` immediately if any repository matches `HuggingFaceFW/fineweb` or `HuggingFaceFW/fineweb-edu` (case-insensitive, normalized).
  - Explicit distinction maintained: distinct, non-FineWeb sources such as `HuggingFaceFW/finewiki` and `HuggingFaceFW/finepdfs-edu` remain eligible candidate names.
- **Silent Fallback Prevention**:
  - `check_silent_fallback()` raises `SilentFallbackDeniedError` if a requested source is substituted, fallen back to default, or implicitly renormalized without explicit configuration.
- **License & Governance Rules**:
  - Requires documented license expressions (`mit`, `apache-2.0`, `cc-by-4.0`, `odc-by`, etc.) and provenance flags.
  - Rejects unknown or non-commercial licenses unless explicitly justified.
  - Software explicitly asserts `LEGAL_DISCLAIMER`: records evidence and policy status; does not purport to certify legal rights.

### 2.3 Bounded Transport & Metered Streaming (`src/xlm/data/sources/transport.py`)
- **`TransportBudget`**:
  - Enforces 32 MiB total transferred byte ceiling per discovery session.
  - Enforces 64 MiB total uncompressed data ceiling.
  - Enforces max request limit (default 20 requests) and per-request timeout deadlines (default 10.0s).
- **`SafeRedirectHandler` & Host Security**:
  - Strictly restricts network requests to allowlisted domains (`huggingface.co`, `hf.co`, `cdn-lfs.huggingface.co`, `raw.githubusercontent.com`, `127.0.0.1`, `localhost`).
  - Intercepts HTTP 301/302/307/308 redirects and verifies that redirection targets are also on the allowlist, preventing SSRF and exfiltration attacks.
- **Provider Transports**:
  - `HuggingFaceTransport`: Queries repository metadata, resolves immutable Git commit SHAs, detects gated/private states without accepting click-through terms, and samples view files within strict range-request budgets.
  - `HttpsManifestTransport`: Fetches remote JSON/YAML manifests over HTTPS with optional SHA-256 integrity verification.
  - `LocalManifestTransport`: Resolves local file manifests with root boundary validation preventing path traversal (`../`) and blocking executable file extensions (`.exe`, `.dll`, `.bat`, `.sh`, `.ps1`).

### 2.4 Schema Inspection, Redaction & Fingerprinting (`src/xlm/data/sources/schema.py`)
- **`arrow_schema_to_view_schema`**:
  - Recursively maps PyArrow and Parquet schemas into `ViewSchema` and `FieldDescriptor` trees.
  - Handles nested Structs, Lists, and Maps.
  - Evaluates schema compatibility against declared `RowExtractorContract` requirements. A missing or invalid text column fails explicitly with `MissingRequiredFieldError` without guessing or falling back.
- **`RedactionUtility`**:
  - Scrubs Hugging Face tokens (`hf_...`), generic API keys (`api_key=...`, `bearer ...`), and invisible terminal/ASCII control characters from logged sample previews.
  - Binds text previews to a max length (default 256 characters) to prevent runaway memory or log pollution.
- **`compute_probe_fingerprint`**:
  - Computes a deterministic SHA-256 fingerprint over `(source_id, view_id, provider, repository, revision, file_digests, schema_hash)`.
  - Guarantees cache invalidation when upstream data, schemas, or revisions change.

### 2.5 Prober & Evidence Persistence (`src/xlm/data/sources/prober.py`, `admission.py`)
- **`SourceProber`**:
  - Executes bounded discovery probes, classifying results into explicit `ProbeOutcome` values (`ACCESSIBLE`, `GATED_OR_PRIVATE`, `INACCESSIBLE_OR_NOT_FOUND`, `REVISION_MISSING`, `SCHEMA_MISMATCH`, `BUDGET_EXHAUSTED`, `TRANSIENT_ERROR`).
  - Distinguishes `EvidenceType.REAL_OBSERVED` from `EvidenceType.SYNTHETIC_FIXTURE`.
  - Ambiguous upstream 500 server errors are strictly marked as `TRANSIENT_ERROR`, never inferred as non-existent (404).
- **`AdmissionGate` & Status Verification**:
  - Admission requires all four mandatory gates:
    1. Direct-source denial check passes (no FineWeb).
    2. Real observed evidence (`EvidenceType.REAL_OBSERVED`) with status `ACCESSIBLE` and immutable revision commit SHA.
    3. Matching probe fingerprint and schema compatibility.
    4. Explicit operator approval (`operator_approved: True`).
  - **Operator Invariance**: Operator approval cannot override missing mandatory evidence, synthetic test fixtures, or direct-source denial.
- **P01 Artifact Store Integration**:
  - Probes persist `ProbeEvidenceRecord` artifacts under `probe_evidence/probe_{source_id}_{view_id}` with SHA-256 verification.
  - Admission decisions persist `AdmissionDecision` artifacts under `admission_decision/admission_{source_id}_{view_id}`.

### 2.6 CLI Commands (`src/xlm/cli/data_cmd.py`)
- `xlm data sources --catalog <path>`: Tabulates candidate catalog entries with approval status, provider, and denial policies.
- `xlm data probe --catalog <path> --source <id> [--view <id>] [--live]`: Runs discovery probe against candidate and persists evidence artifact.
- `xlm data audit --catalog <path>`: Audits entire candidate catalog against stored evidence and admission gate, confirming all candidates remain unadmitted.
- `xlm data admit --catalog <path> --source <id>`: Attempts admission evaluation for a candidate, enforcing mandatory gate requirements.
