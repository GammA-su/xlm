## Implementation and preserved contracts

The existing queue now launches captured code in a fresh controlled process and
passes a versioned execution envelope into the existing Trainer, checkpoint
manager, and evaluator. There is no alternate trainer, artifact store, evaluator,
or production orchestrator. The research/evaluation contract files and Python/
dependency pins retain their recorded hashes. The original D06 before-test,
`before.log`, `before.xml`, and original `observed.json` files remain unchanged.

The execution envelope binds resolved defaults, actual source bytes, lock and
installed runtime identity, selected extras, input/tokenizer content, component
serializers, seeds, and runtime policy. The plan additionally binds operational
limits and lineage; admission is bound to the existing ledger authorization.
Persisted labels alone cannot establish compatibility. Captured A executes after
live B changes; damaged A is refused. Actual worker PID, Trainer origin, authored
behavior, and imported XLM source bytes are tested.

Checkpoint/runtime/run provenance uses the verified context. Evaluation preserves
training provenance and records a separate evaluator identity. D01 immutable
conflicts remain enforced. Historical artifacts are not rewritten. Domain-only
diagnostics remain explicitly unresolved and cannot qualify for frozen resume.

Recovery retains the existing retry policy while correcting first-attempt double
counting. A stale heartbeat cannot trigger another runner while the recorded owner
or worker remains alive. A crashed attempt resumes its verified committed checkpoint
through the existing loader, preserving earlier immutable publications. Ordinary
execution failures remain terminal. A concurrent runner is refused by the per-job
ownership lock. CUDA lease manager logic is tested without GPU execution.

See [the user guide](../../frozen-execution.md) for precise fingerprint exclusions,
trusted startup/OS assumptions, capture/input/setup/output/disk bounds, continuation
rules, and the distinction between inspection and verified execution evidence.
