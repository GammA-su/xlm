## 3. Closeout corrections in this stage (narrow, with evidence)

1. **Windows resolve()-form race in artifact containment (real defect, fixed).**
   `Path.resolve()` returns a `\\?\`-prefixed form when the path can be opened
   and the plain form otherwise, so `_checked_destination`'s
   `resolve().is_relative_to()` flipped on concurrent directory creation
   (captured: identical raw path resolving both ways milliseconds apart).
   Controlled stress reproduced 4/300 serially. Fix: `comparable_resolved()`
   strips the prefix before comparing; symlink/junction rejection stays first
   in `ensure_plain_path`. Applied to `store.py` and the identical pattern in
   `manifest.py::validate_manifest_path`. Post-fix stress 300/300; new
   deterministic unit test kept. No serial workaround, no redesign.
2. **Operator request double-construction tick race (real defect, fixed).**
   `build_final_request` embeds wall-clock construction time in the auth hash;
   the test authorized one construction and executed another, so a Windows
   clock-tick boundary produced `authorization does not match this exact
   request hash` instead of the intended refusal — serially, not only under
   load. Fix (test-only, narrow): authorize the exact object executed in each
   block; the deterministic `ttl_seconds=-10` expiry case and all three refusal
   assertions are unchanged. Passes serially and at `-n 8`.
3. **Serial markers (documented, tests still run).** `@pytest.mark.serial` on
   the measured inventory test (pre-existing), the concurrent-publishers test
   (inner race retained; fails at `-n 16`, passes serially), registered in
   `pyproject.toml` via the shared tooling commit. The operator test needed no
   marker after its determinism fix.
4. **Locale handling: no change.** Zero `UnicodeDecodeError` occurrences across
   all integrated runs; every locale-flagged test passes at `-n 8`/serial, and
   the remaining failures in those files have demonstrated non-locale roots
   (immutable conflict, legacy plan). Per policy, no blanket `errors="replace"`
   was added to JSON/hash/manifest paths; D07's flag is preserved as an
   observation.
5. **D06 300-second proposal: not applied.** Recorded with measurements in
   `P23-D02.md`; inventory-bound failures below are reported as load behavior.
