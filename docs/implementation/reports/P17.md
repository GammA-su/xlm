## 3. Implemented Architecture

### 3.1 Comparison tracks (`comparison/tracks.py`)

Six tracks — architecture, objective, optimizer, tokenizer, data-mixture,
unconstrained-system — each with an explicit fixed/allowed field schema over 22
run facts. Every required fact must be known (fail closed), the tokenizer track
additionally requires matched-bytes and matched-compute evidence, and
continuation-prefix vs standalone horizon tags can never compare as identical.
`ComparisonRun.from_records` assembles facts from P15 evidence plus P16 plans;
explicit caller facts override inferred ones.

### 3.2 Paired cluster bootstrap (`comparison/bootstrap.py`)

Resampling unit is the cluster (BLiMP subdataset or frozen source group);
resampling is stratified within tasks so a draw can never silently drop a whole
task. Suite-index intervals recompute per-arm indexes per replicate through the
P15 formula (BLiMP macro first). Between-seed spread is reported separately; a
single seed states unmeasured variability. Mismatched IDs, missing predictions
and partial coverage raise instead of producing numbers.

### 3.3 Learning curves (`comparison/curves.py`)

Target crossing interpolates between measured points only; unreached or
out-of-range targets return None with reasons, never invented compute.
Compute-to-target uses measured per-point compute, a caller-declared throughput
(labeled estimate), or stays unknown. Teacher/auxiliary costs are additive and
labeled. Head-to-head comparison requires both arms to have reached the target.

### 3.4 Promotion (`comparison/promotion.py`, `xlm compare`, `xlm promote`)

Frozen `PromotionGates` v1 (+1 suite point or ≥10% measured compute saving,
≥2 seeds each, CI excludes zero, regression warnings, search-stage-only CI
semantics). Thresholds are inputs — scores never rewrite them. Passing
evaluations emit schema-validated from-scratch 150m/300m drafts with lineage
sidecars and projected ETAs; failing ones write only the decision. Factorial
and ablation generators emit plan matrices, never jobs.

## 7. Honest Scope Statements

- **Every number is synthetic.** Bootstrap intervals, index deltas and ETAs come
  from authored fixtures to prove the machinery, not from trained models.
- **No live comparison ran.** Real evidence files (P15) and plans (P16) plug into
  the same entry points; none were available at campaign scale.
- **Cluster maps are caller-supplied.** BLiMP comparisons refuse per-item
  resampling without an explicit map; default clusters are per-item only for
  non-BLiMP tasks and the choice is recorded.
- **Search-stage CIs are decision support.** The multiplicity note accompanies
  every decision; no confirmatory claim is made from adaptive selection.
