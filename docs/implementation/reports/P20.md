## 3. Implemented Architecture

### 3.1 Native export (`export/writer.py`, `export/manifest.py`)

`xlm export` writes `model.safetensors` (shared tied tensors cloned, both
aliases stored bitwise-equal), `config.json`, `tokenizer/` and
`export_manifest.json`: format/serializer versions, model/config/tokenizer
hashes, special IDs, normalization policy, generation defaults, tied mapping,
deployed/active/training-only parameter accounting, data-manifest references
(never content), budget, evidence status and cache labeling. Optimizer state is
excluded unless explicitly opted in; training-only objective heads are excluded
with accounting; secrets fail the whole export; raw corpora, credentials and
run files can never enter.

### 3.2 Verified loading (`export/loader.py`, serialization fallback)

Hashes are checked before any deserialization; incomplete/corrupt bundles name
their file. Unknown formats/serializers/plugins are refused with migration
guidance. Tied aliases must match bitwise before Parameter identity is
restored; tokenizer fingerprint and special IDs must match exactly. CPU and
CUDA float32/float16/bfloat16 loads supported; bf16/fp16 off-CUDA refused.
`load_model_from_directory` prefers `model.pt` and falls back to
`model.safetensors`, so existing `generate`/`evaluate` commands read exports.

### 3.3 Sessions and HF mapping (`inference/session.py`, `export/hf.py`)

`xlm generate-session` runs bounded multi-prompt sessions with per-prompt seed
derivation, stop-string handling and saved transcripts; replay is exact. No
chat template exists anywhere in the path. The optional HF layer maps the
baseline — and only the baseline — onto the Llama layout with complete
key/shape/config verification; anything else is refused as a false family
claim. HF *runtime* parity needs transformers on the operator side: NOT RUN.

## 7. Honest Scope Statements

- **HF runtime parity is NOT RUN.** Mapping exactness is tested; executing a
  transformers model needs that library plus their checkpoint (operator side).
- **The manifest is the trust root, not self-hashed.** Payload files are
  hash-pinned; manifest authenticity is a release-signature concern (P21).
- **No cache exists.** Exports label `cache_support: false`; the no-cache path
  is the only path until a tested cache lands.
- **Nothing was published anywhere.** Export writes local directories only.
