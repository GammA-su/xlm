## 2. Implemented Architecture & Components

### 2.1 Boundary Tokenization Conventions (`src/xlm/evaluation/likelihood.py`)
- **`BoundaryPolicy`**:
  - `JOINT_PREFIX_MATCH_V1`: Tokenizes context and concatenation jointly. Asserts that the context tokens form an exact prefix of the joint tokens. If a BPE merge crosses the context/continuation boundary, raises `CrossBoundaryMergeError` rather than silently assigning zero targets.
  - `SEPARATE_V1`: Tokenizes context and continuation independently and concatenates token ID sequences, guaranteeing boundary independence and non-zero scored continuation targets under all circumstances.
- **`prepare_token_pair`**:
  - Encapsulates text-to-token preparation separate from numerical scoring.
  - Handles empty context by injecting a single `<bos>` token.
  - Enforces character/byte slice mapping and non-empty continuation targets.

### 2.2 Native Conditional Likelihood Scoring (`src/xlm/evaluation/likelihood.py`)
- **`ConditionalLikelihoodScorer`**:
  - **Read-Only Invariant**: Runs under `torch.no_grad()`, sets `model.eval()`, and restores caller training mode (`model.training`) in a `finally:` block without mutating optimizer state or gradients.
  - **Exact Target Shifting**: Shifted strictly so that logits at index $t$ predict target at $t+1$. Exposes future-token leakage and shifting bugs via `PrefixDependentToyOracle`.
  - **Batch & Single Parity**: Full numerical agreement between single-item scoring and padded batched forward passes (`score_batch`).
  - **Window Policies (`WindowTruncationPolicy`)**:
    - `ROLLING`: Strided evaluation across long documents with deterministic target ownership (each continuation token scored exactly once).
    - `ERROR`: Immediately raises `ContinuationTooLongError` if the sequence exceeds context window.
  - **Exact Text Bits-Per-Byte (BPB)**:
    - Normalizes token negative log-likelihood sums by total text UTF-8 byte count:
      $$\text{BPB} = \frac{\sum -\ln P(w_t)}{\ln(2) \times \text{bytes}}$$
    - Explicitly excludes structural framing tokens (`<bos>`, `<eos>`, `<pad>`) from byte count.
    - Verified against hand-computable uniform 4-token oracle yielding exactly $2.00000000$ BPB.

### 2.3 Synthetic Benchmark Fixtures & Acc-Norm (`src/xlm/evaluation/fixtures.py`, `scorer.py`)
- **`BenchmarkFixtureDataset`**:
  - Strictly labeled as synthetic development fixtures (`is_offline_fixture=True`, `is_official_benchmark=False`).
  - Authoritative authored multiple-choice (`MultipleChoiceItem`) and minimal-pair (`MinimalPairItem`) test sets.
  - Rejects empty choice strings with `InvalidChoiceError` to prevent division-by-zero during character normalization.
- **`BenchmarkFixtureScorer`**:
  - **Character Length Normalization (`acc_norm`)**: Computes answer score normalized by string character length ($\text{raw\_ll} / \text{len}(choice)$) with deterministic lowest-index tie breaking.
  - **Minimal Pair Evaluation**: Evaluates sentence acceptability conditioned on `<bos>` and computes log-likelihood margins.
  - **Evaluation Receipts**: Emits structured `EvaluationReceipt` artifacts adhering to Contract C12.
- **`RawLikelihoodCache`**:
  - Content-addressable likelihood caching using SHA-256 digests over `(context, continuation, boundary_policy, model_hash, tokenizer_hash, precision, max_context)`.
  - Reuses valid cached results and automatically invalidates across model, tokenizer, or configuration updates.

### 2.4 Diagnostic Validation Aggregation (`src/xlm/evaluation/diagnostics.py`)
- **`evaluate_validation_sources`**:
  - Evaluates validation documents per source.
  - Complying with Amendment 9: aggregates total negative log-likelihood sums, total target tokens, and total UTF-8 text bytes across all documents *before* computing source-level text perplexity and bits-per-byte, preventing unweighted average distortions.

### 2.5 Bounded Autoregressive Generation (`src/xlm/inference/generation.py`)
- **`TextGenerator`**:
  - Stateless text completion engine accepting token sequences or raw text.
  - **Local Generator RNG**: Uses an isolated `torch.Generator(device=...)` for sampling seeds; leaves global PyTorch RNG untouched.
  - **Sampling Controls**: Implements temperature scaling, top-$k$ filtering, top-$p$ (nucleus) sampling with cumulative prob shifting, and repetition penalty.
  - **Prompt Truncation Policies**: Supports `PromptTruncationPolicy.ERROR` (raises `PromptTooLongError`) and `PromptTruncationPolicy.LEFT` (keeps the rightmost tokens to fit within the context window).
  - **Stopping Conditions**: Stops on `<eos>`, configured `stop_tokens`, context window limits, or `max_new_tokens`.

### 2.6 Dedicated Inference Model Loading (`src/xlm/models/serialization.py`)
- **`load_model_for_inference`**:
  - Clean entrypoint for read-only inference and evaluation.
  - Loads model weights and configuration without restoring optimizer, scheduler, or RNG state.
  - Automatically resolves `attention_backend: "profile_required"` to `"eager"` (or explicit `backend_override`) on CPU/inference devices.

### 2.7 CLI Commands & Extended Vertical Slice Demo (`src/xlm/cli/`)
- **`xlm evaluate` (`src/xlm/cli/eval_cmd.py`)**:
  - CLI command to evaluate checkpoints on diagnostic fixtures (`--suite synthetic_mc`, `synthetic_pair`, or `all`) with `--precision`, `--boundary-policy`, and optional `--json` receipt output. Lazy-imports PyTorch.
- **`xlm generate` (`src/xlm/cli/generate_cmd.py`)**:
  - CLI command for text completion from checkpoints with `--prompt`, `--max-new-tokens`, `--temperature`, `--top-k`, `--top-p`, `--repetition-penalty`, and `--seed`. Lazy-imports PyTorch.
- **`xlm demo` (`src/xlm/cli/demo_cmd.py`)**:
  - Extended end-to-end vertical slice demonstration:
    - Part 1: Trains to 100 targets (2 updates x 50 targets) and checkpoints.
    - Part 2: Resumes from checkpoint to 200 targets (4 updates total).
    - Part 3: Evaluates offline diagnostic fixtures (MC and Minimal Pair) and computes document text BPB.
    - Part 4: Generates greedy and sampled text completions.
    - Part 5: Emits structured vertical slice verification summary.
