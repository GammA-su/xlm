## 2. Implemented Architecture & Components

### 2.1 Bias-Free Pre-RMSNorm Transformer (`src/xlm/models/`)
- **`RMSNorm` (`src/xlm/models/rmsnorm.py`)**:
  - Implements Root Mean Square Layer Normalization with eps $\epsilon = 10^{-6}$.
  - Strictly preserves precision (`float64` remains `float64` throughout variance calculation).
  - Uses numerically stable `pow(2).mean(-1, keepdim=True)`.
- **`SwiGLU` (`src/xlm/models/feedforward.py`)**:
  - Bias-free SwiGLU MLP: $\text{SwiGLU}(x) = (\text{SiLU}(x W_{\text{gate}}) \odot x W_{\text{up}}) W_{\text{down}}$.
  - Zero bias parameters across all projections.
- **`TransformerBaseline` (`src/xlm/models/transformer.py`)**:
  - Modular causal decoder-only architecture implementing Contract C08.
  - Pre-normalization layout: input -> RMSNorm -> Self-Attention -> residual add -> RMSNorm -> SwiGLU -> residual add -> final RMSNorm -> LM Head.
  - Weight tying: `lm_head.weight = embed_tokens.weight`, sharing identical underlying `nn.Parameter` storage.
  - Stateless contract: zero persistent KV caches or hidden states across forward invocations.

### 2.2 Rotary Position Embeddings (RoPE) (`src/xlm/models/rope.py`)
- **`RotaryEmbedding`**: Computes inverted frequencies $\theta_i = \text{base}^{-2i/d}$ and precomputes cosine/sine buffers.
- **`apply_rotary_pos_emb`**: Applies rotation to queries and keys using standard interleaved formulation `[-x2, x1]`.
- Explicitly supports arbitrary `position_ids` and non-contiguous sequence positions, enabling exact segment-offset positioning across document boundaries in packed sequences.

### 2.3 Attention Backends & Pre-Softmax Safe Masking (`src/xlm/models/attention.py`, `masks.py`)
- **Pre-Softmax Safe Masking**:
  - Completely avoids blanket `nan_to_num` masking.
  - Dynamically detects query rows where all keys are masked (`valid_rows = ~mask.all(dim=-1, keepdim=True)`).
  - Constructs `safe_mask = mask | (~valid_rows)` so every row has at least one valid key with finite scores, preventing $\text{softmax}(-\infty) = \text{NaN}$.
  - Evaluates standard softmax, then zeros out invalid query rows with `torch.where(valid_rows, attn_weights, 0.0)`.
  - Guarantees exact zero outputs, exact zero gradients on masked positions, and preserves true numerical overflow detection on valid positions.
- **Dual Backends**:
  - `eager`: Exact reference PyTorch implementation computing manual scaled dot-product scores and masked softmax.
  - `sdpa`: High-performance path using `torch.nn.functional.scaled_dot_product_attention`.
- **Fast-Path Causality Guard**:
  - `is_causal=True` is only passed to SDPA when no custom attention mask or segment mask is provided.
  - When explicit masks are provided, the lower-triangular causal mask is combined with the provided mask, and SDPA is invoked with `is_causal=False`, avoiding PyTorch runtime errors and preserving correct masking semantics.
- **Execution Guard**:
  - Recipe presets declare `attention_backend: profile_required`.
  - Instantiating or running forward without explicitly selecting `eager` or `sdpa` raises an explicit `ValueError`.

### 2.4 Document Isolation & Mask Construction (`src/xlm/models/masks.py`)
- **`build_causal_mask`**: Standard lower-triangular causal attention mask.
- **`build_causal_stream_mask`**: Causal mask combined with optional boolean padding mask.
- **`build_isolated_document_mask`**: Combines lower-triangular causality with document segment isolation:
  $$\text{mask}_{i,j} = (i \ge j) \land (\text{segment\_ids}_i == \text{segment\_ids}_j) \land \text{pad\_mask}_j$$
  Prevents any cross-document attention within packed sequences.

### 2.5 Meta-Safe Parameter Accounting (`src/xlm/models/parameter_counts.py`)
- **Meta-Device Safe**:
  - Instantiating models on `torch.device("meta")` assigns `data_ptr() = 0` to all tensors.
  - Parameter deduplication strictly uses Python Parameter object identity (`id(p)` / `p1 is p2`).
- **Comprehensive Counting**:
  - Traverses `named_parameters(remove_duplicate=False)` to discover tied aliases.
  - Reports `total_instantiated`, `unique_deployed`, `active`, `non_embedding`, `tied_parameters`, and exact `formula_estimate`.

### 2.6 Serialization & Tied-Weight Integrity (`src/xlm/models/serialization.py`)
- **`save_model_to_directory`**: Writes `config.json` and `model.pt` with `weights_only=True`.
- **`load_model_from_directory`**: Restores model architecture and state dictionary with `weights_only=True`.
- **Tied Weight Verification**:
  - Verifies that `lm_head.weight` and `embed_tokens.weight` in the checkpoint are bitwise equal.
  - Re-establishes exact Parameter object identity: `model.lm_head.weight = model.embed_tokens.weight`.
  - Rejects corrupted or conflicting tied weights with an explicit `ValueError`.
- **`publish_model_artifact`**: Packages and registers model weights into the immutable artifact store.

### 2.7 CLI Model Subcommand (`src/xlm/cli/model_cmd.py`)
- Subcommand `xlm model inspect <preset_or_path>`:
  - Supports named presets (`tiny`, `50m`, `150m`, `300m`) and custom YAML file paths.
  - Supports `--device meta` (default) and `--device cpu`.
  - Supports `--json` for machine-readable JSON output.
  - Supports `-t/--tokenizer-artifact` for compatibility checking (`check_tokenizer_model_compatibility`).
  - Implements lazy loading so running `xlm --help` or `xlm model --help` does not import PyTorch.
