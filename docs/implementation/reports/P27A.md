## Defects found by the new tests (fixed)

1. `ShardedJsonlWriter.write_line` used `StreamingJsonlWriter.write_raw`
   (hash/size only, no count) → all `doc_count`s were 0 and finish-time
   verification failed. Fixed to `write_line` (one word); counts, totals,
   and aggregate identity now verify.
2. Crash-prefix test wrongly compared full rerun shard sets against the
   crashed run's rolled prefix; corrected to prefix comparison.
3. White-box corruption test appended bytes that the writer's own buffered
   flush overwrote on close; corrected to flush-before-corrupt.

## Open limitations

- RSS bound in the 128 MiB test is generous (+1024 MiB); observed +2.2 MiB
  on this machine only. Wall times are reported, never gated.
- `adopt` is a tested primitive, not wired resume: a crashed adapt is
  recovered by rerun (fail-closed), not by reconnect.
- Throughput scales with the adapter's per-record cost; the 2753 rec/s
  figure is CommonPile-like synthetic prose on one Windows CPU box, not a
  claim about live corpora.
- Manifest re-verification rereads shard bytes (verification, not
  production); producers never reread to learn hashes/counts.
