## 3. Implemented Architecture

### 3.1 Idea cards (`research/ideas.py`)

Versioned cards with all prompt-required fields: bottleneck, mechanism, original
element, dated prior art with sources/search terms, predictions, falsification
experiment, allowed information, costs, baselines, ablations, tuning allowance,
kill/promotion rules, result status. Eight lifecycle statuses; none certifies
novelty — validation actively refuses certainty phrasing ("first ever",
"proven novel", "nobody has ever"). Missing definitions are blockers.

### 3.2 Plugin loader and guards (`research/loader.py`, `research/capabilities.py`)

Plugins are directories with a strict `plugin.yaml`. Loading verifies manifest,
file scope (declared files exist in-dir, no undeclared files execute, no path
escapes), protected surfaces (evaluation code, sealed manifests, baseline
settings, trainer, scorer, checkpoint), the enabled flag, capabilities, then
registers into caller-supplied registries. Capability checks cover recurrent
state reset, auxiliary outputs, accumulation protocols, optimizer closures,
deterministic scoring, parameter caps, cache declarations and inference-only
inputs; violations name the missing support at plan time.

### 3.3 Four no-op plugins (`src/xlm/plugins/`)

One working, explicitly nonnovel control per category — baseline Transformer
subclass, the existing pass-through objective, baseline-AdamW subclass,
byte-tokenizer subclass — each with typed config, registry wiring, capability
and accounting declarations. Baseline parity is exact (logits bitwise,
loss/state equality, identical updates, identical fingerprints and scores).

### 3.4 Scaffold generator (`research/scaffold.py`, `xlm research`)

`idea new` writes a blank proposed card (validation fails until filled);
`idea validate` lists blockers; `scaffold` emits typed config, registry wiring,
accounting/serialization stubs, causal and tiny-overfit templates, a
disabled-mode test and a comparison recipe — disabled by default, failing
explicitly on load, instantiation, accounting and serialization;
`check-plugin` verifies into isolated registries. `idea new` points at
CHANGE_EXPERIMENT_TEMPLATE.md for the idea→patch→smoke→matched→comparison chain.

## 7. Honest Scope Statements

- **No research claim is made.** The no-op plugins are controls, the scaffold is
  unimplemented by design, and no idea card leaves `proposed` without evidence.
- **Prior-art review is a record, not a search engine.** Cards store dated
  sources and search terms; nothing here browses literature or proves absence.
- **No provider integration exists.** Idea generation stays user/external-model
  supplied; no paid calls, no invented references, no sealed-benchmark agent.
- **Secret patterns are heuristics.** Basename matching fails closed on
  suspects; `tokenizer_*` filenames were scoped out after a legitimate collision.
