## Changes and fixture audit

1. Classified original timing matrices as `performance`, and large equivalence /
   resource bounds as `scale`; retained all originals. Added five small dedup
   oracles. Ordinary optimized cleaning, tokenization, split and semantic exactness
   stay in A, with installed optional-backend checks explicit in D; the existing
   60-document cleaning-scale module also stays in A.
2. Marked real worker-pool, process-kill, recovery and runtime-inventory tests
   serial. Isolated CLI subprocess tests remain parallel where safe. Existing
   process lifecycle, rename, fsync, locking and crash assertions are preserved,
   including intentional failure injection. No new mock replaces those operations.
3. Deferred evaluation-harness imports to a session fixture requested only by
   selected optional tests. Collection still imports torch and PyArrow because
   existing class/type definitions require them; no production refactor was made.
4. Replaced two missing checkout-local Parquet fixture prerequisites with authored
   session fixtures: generator/config-keyed temporary files, read-only permissions,
   immutable path mapping, and SHA-256 verification at teardown. Their schema
   assertions are unchanged. This repairs clean-worktree reproducibility.
5. Reused immutable frozen-input **bytes**, built once per session by the original
   real generator. The hash binds the generated tree, captured code, configuration,
   seed/count and installed runtime identity. Every consumer materializes private
   files and creates a fresh ledger and queue through real admission. Custom
   trainer behavior still builds a fresh fixture. Real worker environment checks
   are never cached or patched. No persistent cache or mutable model is shared.
6. Added an optional evidence plugin, not a runner. It writes atomic local JSON
   with selected worker IDs, phase outcomes/durations and sampled process-tree RSS.
   Worker selection agreement and reported-node completeness are checked in the
   evidence reduction. Tests run directly without it.
7. Fixed a Windows termination race exposed by the serial run. The crash test
   previously killed descendants but waited only for its top-level process;
   immediate recovery could still see a live owner. It now waits up to ten seconds
   for those same owned descendants and raises an explicit error if any remain.
   Every original recovery/checkpoint assertion is unchanged. The focused repaired
   test passed in 89.83 seconds; the original failed run is retained in evidence.
